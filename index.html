Control o pedal Bluetooth

Botón para pasar de tema

Los pedales pasa-páginas andan sin configurar nada: Avanzar página pasa al tema siguiente y Retroceder página vuelve al anterior (sincronizando, marcan y deshacen). Para otro control, tocá Aprender y apretá su botón. Los controles de selfie, como el del trípode Xiaomi, mandan subir volumen, y Android casi siempre se queda con esa tecla: si al aprender no aparece nada, es eso.

Configurar Client ID de Google

1. Entrá a console.cloud.google.com → creá un proyecto.
2. APIs y servicios → habilitá Google Drive API.
3. Pantalla de consentimiento OAuth → tipo Externo, y agregate como usuario de prueba.
4. Credenciales → ID de cliente OAuth → tipo Aplicación web.
5. En Orígenes autorizados de JavaScript poné la URL exacta desde donde abrís este archivo (por ejemplo https://tu-app.vercel.app o http://localhost:3000).
6. Copiá el Client ID acá y tocá Conectar.

La app usa el scope appdata: guarda en una carpeta privada de tu Drive que solo ve esta app. No puede leer ni tocar el resto de tus archivos.

Respaldo cifrado

Sin PIN

Con un PIN, el respaldo .json y la copia de Drive se guardan cifrados: sin el PIN no se pueden leer. En el dispositivo las letras siguen a la vista, así que para tocar no hace falta ponerlo. Un PIN de 4 números frena a un curioso; para algo más serio, usá 8 o más. Si te olvidás el PIN, los respaldos cifrados y la copia de Drive no se pueden abrir más: los temas siguen en cada dispositivo. Si lo cambiás o lo sacás, los otros dispositivos se enteran cuando sincronizan con Drive.
