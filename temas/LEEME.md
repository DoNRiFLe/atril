# Carpeta de trabajo para los temas

Poné acá el audio y la letra de cada canción, con el **mismo nombre**:

```
temas/
  perro-verde.mp3
  perro-verde.txt      <- la letra, un renglón por línea
```

Arrastrá el `.mp3` sobre `tools\alinear.bat` y te deja `perro-verde.lrc` al lado.
Después lo importás en el Atril: **☰ Temas → Importar**.

El contenido de esta carpeta está ignorado por git (menos este archivo): los
audios y las letras quedan solo en tu máquina.
